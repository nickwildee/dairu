# 속지 디자인 작업 지침

이 디렉토리에서는 채택한 일러스트를 쓰는 속지와 그림 없이 글자·선·표로 구성하는 속지를 디자인한다.

## 작업 전 확인

- 대화만 하는 요청도 저장소 루트 `AGENTS.md`, `PROGRESS.md`, 이 파일을 먼저 읽는다.
- 이어서 [미드저니 활용과 속지 제작 흐름](MIDJOURNEY_WORKFLOW.md)을 읽는다. 시안 기획, 프롬프트 작성, 결과 피드백만 하는 대화에도 적용한다.
- 일러스트를 사용할 경우 해당 작업에 있는 스타일 문서, 브리프와 채택 결과 기록을 읽고 실제 파일을 확인한다. 그림 자체를 수정하는 작업이면 `illustrations/AGENTS.md`도 읽는다.
- 그림 없는 속지는 사용자가 제공하는 디자인 레퍼런스에서 시작한다. 아직 받지 못했다면 자료를 요청한다. 받으면 제목 배치, 글자 크기, 표 구조, 선과 여백 중 어떤 특징을 참고할지 함께 정한다. 확인된 요소와 기록 항목으로 레이아웃을 직접 구성한다.
- 개별 속지의 실제 규격, 기록 내용과 편집 도구 등 미정인 제작 조건은 사용자와 정한다. 임의의 제작 기준을 추가하지 않는다.

## 현재 적용할 원칙

- 레퍼런스 분석이 끝나면 [공통 지침](../AGENTS.md)의 네 줄 보고서에 참고할 특징, 프롬프트나 편집 방향, 예상 배치를 담는다. 사용자가 원하면 에이전트가 임시 이미지로 그림·제목·기록 공간의 위치와 분위기를 보여준다.
- 사용자의 요구가 충분히 구체화되었다는 확인을 받기 전에는 제작을 시작하지 않는다.
- 기록 칸, 표, 제목, 일러스트 배치와 출력 조건을 사용자와 정한다. 크기, 여백, 색감과 인쇄 규격을 임의로 확정하지 않는다.
- 작은 중간 결과를 보여주고 사용자에게 확인받으면서 진행한다. 여러 단계나 변형을 함께 요청하면 사용자가 명시한 범위까지 진행한다.
- 미드저니 시안을 쓰기로 한 경우 에이전트가 전체 분위기, 장식과 배치를 위한 프롬프트와 설정을 안내하고 사용자가 생성한다.
- 시안 채택, 정확한 문구와 표의 편집 확인, 최종 출력 확인을 구분한다. 실제 크기와 한글 문구, 금액, 날짜, 칸 수와 간격은 별도로 검수한다.
- 일러스트의 배치와 표시 크기를 조정할 수 있다. 그림 자체의 수정이 필요하면 변경 범위를 먼저 확인하고 `illustrations/`의 원본에 반영한다.
- 원본과 사용용 결과물을 구분하고, 실제 작업이 생기면 해당 작업 안에서 `source/`와 `exports/`를 사용한다.
- 확인 내용, 미정 사항, 실제 완료 내용과 다음 단계를 `PROGRESS.md`에 기록한다. 채택한 원본과 최종 PDF는 다시 열 수 있는 클라우드 경로와 버전을 남긴다.
