# dairu

사용자와 대화하면서 일러스트를 제작하고, 그 일러스트를 활용해 현금생활 속지를 디자인하는 저장소입니다.

## 작업 시작

프로젝트 작업 기준 경로는 저장소 루트입니다. 현재 클라우드에서는 `/workspace/dairu`입니다.

```sh
cd /workspace/dairu
```

대화로 하는 기획과 이미지 분석을 포함해 작업 전에 아래 문서를 읽습니다.

1. [공통 행동규칙](AGENTS.md).
2. [현재 진행 기록](PROGRESS.md).
3. [일러스트 작업 지침](illustrations/AGENTS.md) 또는 [속지 작업 지침](inserts/AGENTS.md).
4. 작업 대상 스타일의 분석 문서와 해당 작업의 브리프, 프롬프트, 결과 기록.

## 작업 공간

- `illustrations/`: 레퍼런스 분석과 스타일 분류, 프롬프트 작성, 미드저니 일러스트 제작.
- `inserts/`: 일러스트를 활용한 속지 배치, 기록 칸과 표, 출력 디자인.

사용자에게 요청과 다음 단계의 범위를 확인받고, 작은 중간 결과를 검토하면서 진행합니다. 확인된 스타일 폴더와 실제 제작 파일은 작업이 생길 때 만듭니다.

## 클라우드에서 이어가기

- 현재 작업 공간에는 `/workspace/AGENTS.md`에 저장소로 연결하는 진입 안내를 둡니다. `/workspace`에서 시작해도 `/workspace/dairu`의 지침을 먼저 읽고 작업하도록 안내합니다.
- 이 상위 안내는 저장소 밖에 있어 새 클라우드 환경에 자동으로 전달되지 않습니다. 새 환경에서는 실제 저장소 위치를 작업 대상으로 열어 루트 지침을 읽도록 합니다.
- 새로 체크아웃하는 환경에서도 지침을 사용하려면 이 파일들과 지침이 포함된 저장소 버전을 가져와야 합니다. 로컬 파일 작성, Git 커밋, 원격 반영 여부는 구분해서 확인합니다.
- 이 문서와 `AGENTS.md`는 클라우드 서비스 자체의 기본 시작 폴더 설정을 바꾸지 않습니다.
