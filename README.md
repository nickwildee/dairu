# dairu

현금생활 속지 디자인을 위한 저장소입니다. 채택한 일러스트를 배치하거나, 사용자가 제공한 레퍼런스를 바탕으로 그림 없이 제목·표·기록 칸을 디자인합니다.

## 작업 시작

프로젝트 작업 기준 경로는 저장소 루트입니다. 현재 클라우드에서는 `/workspace/dairu`입니다.

```sh
cd /workspace/dairu
```

대화로 하는 기획과 이미지 분석을 포함해 작업 전에 아래 문서를 읽습니다.

1. [공통 행동규칙](AGENTS.md).
2. [현재 진행 기록](PROGRESS.md).
3. [일러스트 작업 지침](illustrations/AGENTS.md) 또는 [속지 작업 지침](inserts/AGENTS.md).
4. 작업 대상 스타일의 분석 문서와 해당 작업의 브리프, 프롬프트, 결과 기록.

## 작업 공간

- `illustrations/`에서 에이전트가 미드저니 프롬프트를 작성하고 사용자가 생성한 결과를 함께 검토합니다.
- `inserts/`에서 일러스트 유무에 맞춰 레이아웃을 구성하고 실제 규격으로 PDF 등을 편집합니다.

속지 디자인에서 미드저니로 시안을 만들고 실제 편집과 출력 검토로 이어가는 절차는 [미드저니 활용 가이드](inserts/MIDJOURNEY_WORKFLOW.md)를 참고합니다. 프롬프트와 설정은 에이전트가 준비하고, 미드저니에서의 생성은 사용자가 수행합니다.

사용자에게 요청과 다음 단계의 범위를 확인받고, 작은 중간 결과를 검토하면서 진행합니다. 확인된 스타일 폴더와 실제 제작 파일은 작업이 생길 때 만듭니다.

## 클라우드에서 이어가기

새 채팅을 `nickwildee/dairu`에서 시작하면 첫 메시지부터 작업을 요청할 수 있습니다. 다른 프로젝트에서 시작한다면 “`nickwildee/dairu` 기준으로 진행해”라고 처음에 한 번 지정하면 됩니다. 이후 에이전트는 프로젝트 요청마다 지침과 진행 기록을 읽습니다.

저장소 밖의 `/workspace/AGENTS.md`는 새 클라우드 환경에 따라오지 않습니다. 저장소의 지침은 작업 규칙을 설명하며, 채팅의 시작 폴더를 바꾸거나 파일 열람을 자동 실행하지는 않습니다.

작업 파일은 클라우드에만 보관합니다. 다음 채팅에서는 진행 기록에 적힌 클라우드 경로와 버전으로 채택한 원본과 최종 PDF를 찾습니다.
